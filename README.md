# General Video-to-Anime Translation with Scenimefy

Transforming real-world videos into anime-style videos by training **Scenimefy** (ICCV 2023), a
semi-supervised image-to-image translation framework, and applying it frame by frame.

**Course project:** Deep Learning: Theory and Practice (IE-643), IIT Bombay, under Prof. P. Balamurugan · Aug–Nov 2024
**Team Projectneo:** Rubul Gogoi, Amitkumar Kumavat

> Built on the official Scenimefy implementation: *Scenimefy: Learning to Craft Anime Scene via
> Semi-Supervised Image-to-Image Translation*, Jiang, Jiang, Yang & Loy (ICCV 2023) ·
> [paper](https://arxiv.org/abs/2308.12968) · [code](https://github.com/Yuxinn-J/Scenimefy).
> All credit for the method goes to the original authors.

## What we did

- **Explored baselines** for image-to-anime translation (pix2pix, CycleGAN, CartoonGAN, AnimeGAN) and
  attempted a custom GAN before selecting Scenimefy.
- **Collected anime data:** extracted 5,958 Shinkai-style scene frames from nine films using the
  frame list provided with Scenimefy.
- **Trained Scenimefy from scratch** using the official codebase, and added checkpoint resumption.
- **Implemented FID evaluation** to measure output quality.
- **Extended image translation to video:** frame extraction → per-frame anime translation → video reconstruction.

## Method (Scenimefy, three stages)

1. **Pseudo-paired data generation:** a StyleGAN source generator (real scenes) and a fine-tuned target
   generator (anime) produce structure-consistent real/anime pairs, guided by CLIP and perceptual losses.
2. **Segmentation-guided data selection:** Mask2Former filters out pairs with low semantic consistency
   (cross-entropy above 5.0) or only one semantic category.
3. **Semi-supervised translation:** a supervised branch on pseudo pairs (conditional GAN + patch-wise
   contrastive *StylePatchNCE* loss) and an unsupervised branch on real/anime data (*Semantic Relation
   Consistency* and *hard-negative contrastive* losses).

## Data

| Dataset | Size | Use |
|---------|------|-----|
| LHQ (real landscapes) | 30,000 images | `unpaired_s2a/trainA` |
| Shinkai anime scenes | 5,958 images | `unpaired_s2a/trainB` |
| Pseudo-paired (StyleGAN) | 30,000 pairs | `pair_s2a` [generated by us / authors' release] |

## Training setup

- Base: Contrastive Unpaired Translation (CUT); generator `resnet_9blocks`; 70×70 PatchGAN discriminator; `mlp_sample` feature head
- Batch size 1, image size 704×704, NCE layers 0, 4, 8, 12, 16, instance normalization
- Loss weights: GAN = 1, hDCE = 1, SRC = 1
- Adam (β1 = 0.5, β2 = 0.999), lr 2e-4 constant for 10 epochs, then linear decay to 0 over 10 epochs

**Limitations observed:**
- Struggles with **human faces** and **crowded scenes** (e.g. close-up portraits, race-car crowds).
- Per-frame translation can cause **flicker** between frames, since temporal consistency is not modelled.
- Training is computationally expensive at 704×704.

**Future work:** temporal-consistency constraints for video, faster inference for real-time use,
and fine-tuning on human-centric anime data.

## Usage

### Inference

```bash
python test.py --dataroot ./datasets/Sample --name shinkai-test --CUT_mode CUT --model cut \
  --phase test --epoch Shinkai --preprocess none
```

### Video

```bash
python frame_extraction_opencv.py   # video -> frames
# run inference on the frames (above)
python image_to_video.py            # translated frames -> video
```

### Training

```bash
python train.py --name exp_shinkai --CUT_mode CUT --model semi_cut \
  --dataroot ./datasets/unpaired_s2a --paired_dataroot ./datasets/pair_s2a \
  --checkpoints_dir ./pretrained_models
```

Resume from a checkpoint:

```bash
python trial.py --continue_train --epoch latest_epoch --epoch_count latest_epoch \
  --preprocess resize_and_crop --name shinkai-test
```

Dataset preparation: see `Anime_dataset/README.md` and `Seg_selection/README.md`.
